# Смены и календарь Ordos

**Ссылка: https://twoaspirine.github.io/ordos-smeny/**

Открывается в любом браузере на телефоне и компьютере, ставить ничего не
нужно. На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“»
— появится иконка как у приложения.

Правки сохраняются в общей базе — что поменял один, у остальных обновляется
за пару секунд. Индикатор вверху: `● общая база` — всё синхронно.

Сайт обновляется автоматически при пуше `index.html` в ветку `main`.

## Что внутри

| Экран | Что делает |
|---|---|
| **Смены** | график по неделям и месяцам; смены по дням; красным — будни без людей; перетаскивание сотрудников на дни; сводка часов |
| **Календарь** | турниры, обучалки, игротеки, дни покраса, ивенты — по месяцам, месяцы сворачиваются |
| **Сотрудники** | имя, роль, ставка, статус |
| **Заказы** | что купить в клуб: приоритет, статус, магазин, цена, привязка к мероприятию |
| **Данные** | подключение общей базы, резервная копия, сброс |

Тема светлая/тёмная — кнопка внизу слева (на телефоне — не показана, берётся
из системной темы).

## Общая база

Supabase (Realtime Database, бесплатный тариф). Адрес проекта и публичный
ключ вписаны в `index.html` (блок `HARDCODED` вверху `<script type="module">`).
Данные — одна строка `public.planner` (`id=1`, поле `data jsonb` со всем
графиком). При изменении любой клиент пишет строку целиком, остальные
получают её через Supabase Realtime.

Поменять базу можно и без правки файла — экран **«Данные»**, поля Project
URL + anon key.

**На будущее:** RLS-политики сейчас открыты (`using(true)`). Для клубного
графика по коду входа это ок; при желании ужесточить — Supabase → Auth
Policies.
